2. ESTRUTURA DA APLICAÇÃO

O sistema de biblioteca possui duas entidades principais: Autor e Livro. O modelo Autor armazena nome e nacionalidade. O modelo Livro armazena título, ano, disponibilidade e a relação com um autor.

Trecho do modelo Autor e Livro:

from django.db import models

class Autor(models.Model):
	nome = models.CharField(max_length=200)
	nacionalidade = models.CharField(max_length=150)

	def __str__(self):
		return self.nome


class Livro(models.Model):
	titulo = models.CharField(max_length=250)
	ano = models.IntegerField()
	disponivel = models.BooleanField(default=True)
	autor = models.ForeignKey(Autor, on_delete=models.CASCADE, related_name="livros")

	def __str__(self):
		return f"{self.titulo} ({self.ano})"

Trecho das views que sustentam os testes:

from django.shortcuts import render, redirect, get_object_or_404
from .modelos import Autor, Livro

def criar_autor(request):
	if request.method == "POST":
		nome = request.POST.get("nome")
		nacionalidade = request.POST.get("nacionalidade")

		if not nome or not nacionalidade:
			return render(request, "biblioteca/formulario_autor.html", {"erro": "Campos obrigatórios!"}, status=200)

		Autor.objects.create(nome=nome, nacionalidade=nacionalidade)
		return redirect("listar_livros")

def listar_livros(request):
	livros = Livro.objects.all()
	return render(request, "biblioteca/lista_livros.html", {"livros": livros})

def criar_livro(request):
	if request.method == "POST":
		titulo = request.POST.get("titulo")
		ano = request.POST.get("ano")
		autor_id = request.POST.get("autor")

		if not titulo or not ano or not autor_id:
			return render(request, "biblioteca/formulario_livro.html", {"erro": "Dados inválidos"}, status=200)

		autor = get_object_or_404(Autor, id=autor_id)
		Livro.objects.create(titulo=titulo, ano=ano, autor=autor)
		return redirect("listar_livros")

def emprestar_livro(request, livro_id):
	livro = get_object_or_404(Livro, id=livro_id)
	livro.disponivel = not livro.disponivel
	livro.save()
	return redirect("listar_livros")

3. DESCRIÇÃO DOS TESTES

TESTE 1 - LISTAGEM DE LIVROS

Objetivo: confirmar se os livros cadastrados aparecem corretamente na página de listagem.

Cenário avaliado: o teste cria registros de apoio para autor e livro, acessa a rota de listagem e verifica se os dados salvos no banco são exibidos na interface.

Resultado esperado: a página deve responder com sucesso, o livro deve aparecer na listagem e as informações exibidas devem corresponder aos dados salvos.

Trecho do teste:

def test_listagem_de_livros(self):
	response = self.client.get(reverse("listar_livros"))
	self.assertEqual(response.status_code, 200)
	self.assertTemplateUsed(response, "biblioteca/lista_livros.html")
	self.assertContains(response, "Dom Casmurro")
	self.assertContains(response, "1899")
	self.assertContains(response, "Machado de Assis")

TESTE 2 - CADASTRO DE AUTOR

Objetivo: validar se um novo autor pode ser criado com sucesso por meio da interface da aplicação.

Cenário avaliado: o teste envia os dados do formulário para a rota de cadastro de autor, confirma a criação do registro no banco e verifica o comportamento da resposta.

Resultado esperado: o autor deve ser salvo no banco, a resposta da aplicação deve ser um redirecionamento válido e os campos obrigatórios devem ser aceitos corretamente.

Trecho do teste:

def test_cadastro_de_autor(self):
	dados_autor = {
		"nome": "Clarice Lispector",
		"nacionalidade": "Brasileira"
	}

	response = self.client.post(reverse("criar_autor"), dados_autor)
	self.assertEqual(Autor.objects.count(), 2)
	novo_autor = Autor.objects.get(nome="Clarice Lispector")
	self.assertEqual(novo_autor.nacionalidade, "Brasileira")
	self.assertRedirects(response, reverse("listar_livros"))

TESTE 3 - CADASTRO DE LIVRO

Objetivo: assegurar que um livro possa ser cadastrado vinculado a um autor existente.

Cenário avaliado: o teste envia os dados do livro para a rota de cadastro, usando um autor previamente criado, e verifica se o relacionamento entre as entidades foi mantido.

Resultado esperado: o livro deve ser salvo corretamente, a associação com o autor deve ser preservada e a aplicação deve retornar o comportamento esperado após o envio do formulário.

Trecho do teste:

def test_cadastro_de_livro(self):
	dados_livro = {
		"titulo": "Memórias Póstumas de Brás Cubas",
		"ano": 1881,
		"autor": self.autor.id
	}

	response = self.client.post(reverse("criar_livro"), dados_livro)
	self.assertEqual(Livro.objects.count(), 2)
	novo_livro = Livro.objects.get(titulo="Memórias Póstumas de Brás Cubas")
	self.assertEqual(novo_livro.ano, 1881)
	self.assertTrue(novo_livro.disponivel)
	self.assertEqual(novo_livro.autor, self.autor)
	self.assertRedirects(response, reverse("listar_livros"))

TESTE 4 - EMPRÉSTIMO DE LIVRO

Objetivo: verificar se o sistema altera corretamente o estado do livro quando um empréstimo é realizado.

Cenário avaliado: o teste simula a ação do usuário ao acessar a rota de empréstimo de um livro existente e confirma se o campo de disponibilidade é atualizado no banco.

Resultado esperado: o livro deve ser localizado corretamente, o estado de disponibilidade deve ser alterado e a alteração deve ser persistida no banco.

Trecho do teste:

def test_emprestimo_de_livro(self):
	response = self.client.get(reverse("emprestar_livro", args=[self.livro.id]), follow=True)
	self.assertEqual(response.status_code, 200)
	self.assertTemplateUsed(response, "biblioteca/lista_livros.html")
	self.livro.refresh_from_db()
	self.assertFalse(self.livro.disponivel)
	self.assertContains(response, "Emprestado")
	self.assertContains(response, "Dom Casmurro")

TESTE 5 - VALIDAÇÃO DE CADASTRO

Objetivo: garantir que o sistema rejeite cadastros inválidos e preserve a integridade dos dados.

Cenário avaliado: o teste envia informações incompletas para o cadastro de autor e verifica se a aplicação impede o salvamento indevido.

Resultado esperado: cadastros inválidos não devem ser salvos, a resposta deve apresentar o comportamento correto e as regras de validação devem ser respeitadas.

Trecho do teste:

def test_cadastro_invalido_de_autor_nao_salva(self):
	dados_invalidos = {
		"nome": "",
		"nacionalidade": ""
	}

	response = self.client.post(reverse("criar_autor"), dados_invalidos)
	self.assertEqual(response.status_code, 200)
	self.assertTemplateUsed(response, "biblioteca/formulario_autor.html")
	self.assertContains(response, "Campos obrigatórios!")
	self.assertEqual(Autor.objects.count(), 1)
